## 1. 背景

看板任务增长到两位数后，按标签（backend / frontend / data / ops / urgent）筛选成为高频诉求。
当前 `GET /api/tasks` 只支持 `status`，前端只能拿到全量数据再自行过滤，导致移动端首屏变慢。

## 2. 需求

### REQ-TAG-01 支持 tag 查询参数

`GET /api/tasks?tag=<label>` 只返回 `tags` 数组包含该标签的任务。

### REQ-TAG-02 匹配规则

- 标签匹配**大小写不敏感**：`tag=backend` 与 `tag=Backend` 结果相同。
- 按**完整标签**匹配，不做子串匹配：`tag=back` 不得匹配 `backend`。

### REQ-TAG-03 与 status 组合

当 `tag` 与 `status` 同时出现时，两个条件取交集：
`GET /api/tasks?status=open&tag=backend` 返回既未完成、又带 backend 标签的任务。

### REQ-TAG-04 边界输入

- `tag=`（空字符串）视为未提供该参数，等价于不按标签过滤。
- 未知标签（不匹配任何任务）返回空列表，HTTP 状态码仍为 200，不得报错。

### REQ-TAG-05 兼容性

响应结构 `{"items": [...], "count": n}`、任务字段、`id` 升序排列均保持不变；
`status` 的校验逻辑（REQ-LIST-02）不得改变。

### REQ-TAG-06 参数顺序无关

`?tag=a&status=b` 与 `?status=b&tag=a` 必须返回相同结果，筛选逻辑不得依赖查询参数的书写顺序。

## 3. 非目标

- 不支持多标签 OR / AND 组合（如 `tag=backend,data`），本期不做。
- 不引入数据库或缓存层，数据仍来自 `store.TASKS`。

## 4. 约束

- 不得修改 `tests/` 下任何测试文件来迁就实现。
- 不得破坏 SPEC-001 的既有行为。

## 1. 目的

定义任务看板对外提供的任务列表接口，作为其他规格（如 SPEC-002）的兼容性基线。

## 2. 需求

### REQ-LIST-01 返回全部任务

`GET /api/tasks` 在不带任何查询参数时返回全部任务，按 `id` 升序排列。

### REQ-LIST-02 按状态过滤

- 支持查询参数 `status`，取值只能是 `open`、`in_progress`、`done`。
- 传入非法值时返回 HTTP 400，响应体包含 `error="invalid_status"` 与 `allowed` 数组。
- 不允许用「返回空列表」掩盖非法输入。

### REQ-LIST-03 响应结构

响应体固定为：

```json
{"items": [ ... ], "count": 12}
```

`count` 必须等于 `items` 的长度。

### REQ-LIST-04 任务字段

每个任务包含且仅包含：`id`、`title`、`status`、`tags`、`owner`、`due`。

### REQ-LIST-05 状态枚举

`status` 只有 `open`、`in_progress`、`done` 三种取值，出现在任务数据与过滤参数中。

## 3. 约束

- 本规格描述的行为是兼容性基线，任何后续改动不得破坏 REQ-LIST-01 ~ REQ-LIST-05。
- 测试文件 `tests/test_tasks_api.py` 是这些条目的可执行形式。

## 4. 验收

```bash
pytest tests/test_tasks_api.py -q
```

全部通过即视为满足本规格。

## taskboard/app.py  相关符号: list_tasks(L18-38)
```python
"""HTTP 接口层。

视图函数放在模块级，便于上下文模块按符号定位到具体函数（而不是只能定位到
``create_app`` 这个工厂），也便于测试直接 import。
"""

from __future__ import annotations

from flask import Flask, jsonify, request

from .store import STATUSES, all_tasks, filter_tasks


def health():
    return jsonify({"status": "ok"})


def list_tasks():
    """GET /api/tasks：返回任务列表，支持 status 过滤。

    改前状态：只按 status 过滤，``tag`` 参数被忽略（SPEC-002 待实现）。
    """

    status = request.args.get("status")
    if status is not None and status not in STATUSES:
        return (
            jsonify(
                {
                    "error": "invalid_status",
                    "message": f"status 只能是 {', '.join(STATUSES)}",
                    "allowed": list(STATUSES),
                }
            ),
            400,
        )

    items = filter_tasks(all_tasks(), status=status)
    return jsonify({"items": items, "count": len(items)})


def create_app() -> Flask:
    app = Flask(__name__)
    app.config["JSON_AS_ASCII"] = False
    app.add_url_rule("/api/health", "health", health, methods=["GET"])
    app.add_url_rule("/api/tasks", "list_tasks", list_tasks, methods=["GET"])
    return app
```

    tasks: Iterable[dict],

"""目标功能测试：SPEC-002（按标签筛选）。

改前全部失败（接口忽略 tag 参数，返回全量任务），改后必须全部通过。

from __future__ import annotations


def test_filter_by_tag(client):
    """REQ-TAG-01：只返回 tags 中包含该标签的任务。"""
    body = client.get("/api/tasks?tag=backend").get_json()
    assert body["count"] == 4
    assert {task["id"] for task in body["items"]} == {1, 2, 7, 10}
    assert all("backend" in task["tags"] for task in body["items"])


def test_tag_match_is_case_insensitive(client):
    """REQ-TAG-02：大小写不敏感，Backend 与 backend 等价。"""
    lower = client.get("/api/tasks?tag=backend").get_json()
    upper = client.get("/api/tasks?tag=Backend").get_json()

    # 先确认筛选本身生效，再比较两种大小写结果（避免改前"两边都是全量"而假通过）。
    assert lower["count"] == 4
    assert upper["count"] == lower["count"]
    assert {t["id"] for t in upper["items"]} == {t["id"] for t in lower["items"]}


def test_tag_requires_exact_token(client):
    """REQ-TAG-02：按完整标签匹配，不做子串匹配。"""
    body = client.get("/api/tasks?tag=back").get_json()
    assert body["count"] == 0
    assert body["items"] == []


def test_unknown_tag_returns_empty_list(client):
    """REQ-TAG-04：未知标签返回空列表，HTTP 状态仍是 200。"""
    resp = client.get("/api/tasks?tag=does-not-exist")
    assert resp.status_code == 200

    body = resp.get_json()
    assert body["items"] == []
    assert body["count"] == 0


def test_empty_tag_is_treated_as_absent(client):
    """REQ-TAG-04：tag= 视为未提供，不做任何过滤。"""

    assert all(task["status"] == "open" and "backend" in task["tags"] for task in body["items"])
