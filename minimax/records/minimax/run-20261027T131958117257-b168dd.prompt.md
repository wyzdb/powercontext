# user
## 任务
为 orderflow 的订单列表接口增加按创建时间筛选能力：GET /orders 支持 created_after 参数，取值为 YYYY-MM-DD，边界当天 00:00:00 与 23:59:59 的订单都必须包含，边界前一天的订单必须排除；非法日期返回 HTTP 400，错误码为 invalid_created_after；该参数要和 status、min_total、分页同时生效，先过滤后分页。不得改变原有的分页语义（SPEC-ORD-001）、状态筛选（SPEC-ORD-002）、金额下限（SPEC-ORD-003）与排序规则（SPEC-ORD-005）。

## 必须满足的规格条目
### SPEC-ORD-004/R1 参数形态（specs/SPEC-ORD-004-created-after.md:12-14）
`GET /orders` 新增可选查询参数 `created_after`，取值为 ISO-8601 日历日期，格式固定为 `YYYY-MM-DD`。参数缺省时行为与当前版本一致；参数出现且非空时进入 R2 的过滤逻辑。`created_after` 以原始字符串从 HTTP 层传入服务层，由服务层解析与校验；HTTP 层只做参数透传，不得假设调用方会传入日期对象。

### SPEC-ORD-004/R2 过滤语义（specs/SPEC-ORD-004-created-after.md:16-18）
过滤条件是 `created_at` 的日期部分大于等于 `created_after`，比较按日历日进行，不受时区偏移影响。边界当天的订单必须全部包含：`00:00:00` 与 `23:59:59` 的订单都算命中，边界前一天 `23:59:59` 的订单必须排除。

### SPEC-ORD-004/R3 非法输入（specs/SPEC-ORD-004-created-after.md:20-22）
`created_after` 无法按 `YYYY-MM-DD` 解析时（例如 `2026-13-01`、`2026-9-1`、空值、非日期文本），接口返回 HTTP 400，响应体 `error.code` 为 `invalid_created_after`，并沿用 SPEC-API-001 的错误信封。

### SPEC-ORD-004/R4 与既有筛选、分页的组合（specs/SPEC-ORD-004-created-after.md:24-26）
`created_after` 必须能和 `status`、`min_total`、`page`、`page_size` 同时使用：先做全部过滤，再排序，最后分页；`total` 与 `pages` 按过滤后的集合计算，不得按过滤前的集合计算。

## 不得破坏的既有约束
### SPEC-API-001/R2 业务校验失败（specs/SPEC-API-001-query-contract.md:16-18）
过滤参数或分页参数非法时返回 400，响应体固定为 `{"error": {"code": "...", "message": "..."}}`，`code` 使用服务层抛出的错误码（如 `invalid_status`、`invalid_pagination`、`invalid_min_total`）。

### SPEC-ORD-001/R1 页码与页大小边界（specs/SPEC-ORD-001-pagination.md:12-14）
`page` 是 1 起始的页码，取值必须大于等于 1；`page_size` 取值必须在 `1..100` 闭区间内，默认 20。非整数或越界时抛出 `invalid_pagination`，HTTP 层映射为 400。

### SPEC-ORD-001/R2 total 与 pages 的语义（specs/SPEC-ORD-001-pagination.md:16-18）
`total` 是过滤后的记录总数，`pages` 是 `ceil(total / page_size)`；两者都不能按过滤前的集合计算。响应必须回显调用方实际使用的 `page` 与 `page_size`。

### SPEC-ORD-002/R1 取值与错误码（specs/SPEC-ORD-002-status-filter.md:12-14）
`status` 只接受 `pending`、`paid`、`shipped`、`cancelled` 四个取值；其他取值（包括拼写错误与空字符串）必须抛出 `invalid_status`，HTTP 层映射为 400，不得静默返回空列表。

### SPEC-ORD-003/R1 闭区间语义（specs/SPEC-ORD-003-min-total-filter.md:12-14）
`min_total` 表示订单总额（单位：分）的下界，过滤条件为 `total_cents >= min_total`，等于下界的订单必须保留。

### SPEC-ORD-003/R2 非法取值（specs/SPEC-ORD-003-min-total-filter.md:16-18）
`min_total` 必须是大于等于 0 的整数；负数、非整数文本抛出 `invalid_min_total`，HTTP 层映射为 400。

### SPEC-ORD-005/R1 排序键（specs/SPEC-ORD-005-stable-ordering.md:12-14）
排序键是 `(-total_cents, id)`：总额从高到低；总额相同时按订单号字符串升序。排序必须稳定且与过滤条件无关，翻页前后不能出现同一订单重复或遗漏。

```python
"""HTTP surface for the orderflow demo service (standard library only)."""

from __future__ import annotations

import argparse
import json
from collections.abc import Mapping
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import Any
from urllib.parse import parse_qs, urlparse

from orderflow.models import Order
from orderflow.repository import load_orders
from orderflow.service import DEFAULT_PAGE_SIZE, QueryError, list_orders


class ListQuery:
    """Validated query parameters for ``GET /orders``."""

    def __init__(
        self,
        *,
        status: str | None = None,
        min_total: str | None = None,
        page: str = "1",
        page_size: str = str(DEFAULT_PAGE_SIZE),
    ) -> None:
        self.status = status
        self.min_total = min_total
        self.page = page
        self.page_size = page_size

    def as_filters(self) -> dict[str, Any]:
        filters: dict[str, Any] = {"page": self.page, "page_size": self.page_size}
        if self.status is not None:
            filters["status"] = self.status
        if self.min_total is not None:
            filters["min_total"] = self.min_total
        return filters


def _single(query: Mapping[str, list[str]], name: str) -> str | None:
    values = query.get(name)
    if not values:
        return None
    if len(values) > 1:
        raise QueryError("invalid_query", f"duplicate query parameter: {name}")
    return values[0]


def parse_list_query(query: Mapping[str, list[str]]) -> ListQuery:
    """Turn the raw query string into the parameters the service accepts."""

    return ListQuery(
        status=_single(query, "status"),
        min_total=_single(query, "min_total"),
        page=_single(query, "page") or "1",
        page_size=_single(query, "page_size") or str(DEFAULT_PAGE_SIZE),
    )


class OrderHTTPServer(ThreadingHTTPServer):
    """``ThreadingHTTPServer`` that carries the order data set."""

    daemon_threads = True

    def __init__(self, address: tuple[str, int], orders: tuple[Order, ...]) -> None:
        super().__init__(address, OrderRequestHandler)
        self.orders = orders


class OrderRequestHandler(BaseHTTPRequestHandler):
    """Read-only JSON API for the order list."""

    server_version = "orderflow/1.0"
    server: OrderHTTPServer

    def do_GET(self) -> None:  # noqa: N802 - stdlib callback name
        parsed = urlparse(self.path)
        try:
            if parsed.path == "/health":
                self._json(200, {"status": "ok"})
                return
            if parsed.path == "/orders":
                query = parse_qs(parsed.query, keep_blank_values=True)
                page = list_orders(self.server.orders, **parse_list_query(query).as_filters())
                self._json(200, page.to_mapping())
                return
            self._error(404, "not_found", f"no route for {parsed.path}")
        except QueryError as exc:
            self._error(400, exc.code, exc.message)

    def _json(self, status: int, payload: Mapping[str, Any]) -> None:
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def _error(self, status: int, code: str, message: str) -> None:
        self._json(status, {"error": {"code": code, "message": message}})

    def log_message(self, format: str, *args: Any) -> None:  # noqa: A002
        """Keep the demo quiet; request logging is the caller's concern."""


def make_server(
    host: str = "127.0.0.1",
    port: int = 0,
    orders: tuple[Order, ...] | None = None,
) -> OrderHTTPServer:
    """Create (but do not start) an order API server."""

    return OrderHTTPServer((host, port), orders if orders is not None else load_orders())


def serve(host: str, port: int) -> None:
    server = make_server(host, port)
    print(f"orderflow listening on http://{host}:{server.server_address[1]}", flush=True)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Serve the orderflow JSON API")
    parser.add_argument("--host", default="127.0.0.1")
    parser.add_argument("--port", type=int, default=8080)
    args = parser.parse_args(argv)
    serve(args.host, args.port)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""Order listing rules.

The module is deliberately dependency-free: the demo service must start on a
clean machine with nothing but the Python standard library, and the SDD
context module must be able to index these symbols with ``ast`` alone.
"""

from __future__ import annotations

import math
from collections.abc import Iterable, Sequence

from orderflow.models import Order, Page

STATUSES: tuple[str, ...] = ("pending", "paid", "shipped", "cancelled")
DEFAULT_PAGE_SIZE = 20
MAX_PAGE_SIZE = 100


class QueryError(ValueError):
    """A list-orders request that violates the query contract."""

    def __init__(self, code: str, message: str) -> None:
        super().__init__(message)
        self.code = code
        self.message = message


def normalize_status(status: str) -> str:
    """Return the canonical status token or raise ``invalid_status``."""

    candidate = status.strip().lower()
    if candidate not in STATUSES:
        raise QueryError("invalid_status", f"unknown status: {status!r}")
    return candidate


def parse_page(value: str | int) -> int:
    """Parse a 1-based page number."""

    try:
        page = int(value)
    except (TypeError, ValueError) as exc:
        raise QueryError("invalid_pagination", f"page is not an integer: {value!r}") from exc
    if page < 1:
        raise QueryError("invalid_pagination", f"page must be >= 1: {page}")
    return page


def parse_page_size(value: str | int) -> int:
    """Parse a page size in ``1..MAX_PAGE_SIZE``."""

    try:
        size = int(value)
    except (TypeError, ValueError) as exc:
        raise QueryError("invalid_pagination", f"page_size is not an integer: {value!r}") from exc
    if size < 1 or size > MAX_PAGE_SIZE:
        raise QueryError(
            "invalid_pagination",
            f"page_size must be between 1 and {MAX_PAGE_SIZE}: {size}",
        )
    return size


def parse_min_total(value: str | int) -> int:
    """Parse the inclusive lower bound on ``total_cents``."""

    try:
        minimum = int(value)
    except (TypeError, ValueError) as exc:
        raise QueryError("invalid_min_total", f"min_total is not an integer: {value!r}") from exc
    if minimum < 0:
        raise QueryError("invalid_min_total", f"min_total must be >= 0: {minimum}")
    return minimum


def _sort_key(order: Order) -> tuple[int, str]:
    # SPEC-ORD-005: highest total first, ties broken by ascending order id so
    # repeated pages never reshuffle equal totals.
    return (-order.total_cents, order.id)


def list_orders(
    orders: Iterable[Order],
    *,
    status: str | None = None,
    min_total: int | str | None = None,
    page: int | str = 1,
    page_size: int | str = DEFAULT_PAGE_SIZE,
) -> Page:
    """Return one page of orders after applying the supported filters.

    Filtering happens before sorting and paging, so ``total`` always counts the
    filtered set and ``page`` indexes into it.
    """

    page_number = parse_page(page)
    size = parse_page_size(page_size)
    status_token = normalize_status(status) if status is not None else None
    minimum = parse_min_total(min_total) if min_total is not None else None

    filtered: Sequence[Order] = [
        order
        for order in orders
        if (status_token is None or order.status == status_token)
        and (minimum is None or order.total_cents >= minimum)
    ]

    ordered = sorted(filtered, key=_sort_key)
    total = len(ordered)
    start = (page_number - 1) * size
    items = tuple(ordered[start : start + size])
    pages = math.ceil(total / size) if total else 0
    return Page(items=items, total=total, page=page_number, page_size=size, pages=pages)
```

```python
"""Target acceptance tests for SPEC-ORD-004 (created_after filter).

These tests describe the requested behaviour, so they fail against the
unmodified service and pass once the change is applied.
"""

from __future__ import annotations

from conftest import get_json


# spec: SPEC-ORD-004/R1
def test_created_after_filters_orders(api_base: str) -> None:
    status, body = get_json(f"{api_base}/orders?created_after=2026-09-15&page_size=10")
    assert status == 200
    assert [item["id"] for item in body["items"]] == [
        "ORD-2004",
        "ORD-2002",
        "ORD-2003",
    ]
    assert body["total"] == 3


# spec: SPEC-ORD-004/R2
def test_created_after_includes_the_boundary_day(api_base: str) -> None:
    _, body = get_json(f"{api_base}/orders?created_after=2026-09-15&page_size=10")
    ids = [item["id"] for item in body["items"]]
    assert "ORD-2002" in ids, "an order at 00:00:00 on the boundary day must be included"
    assert "ORD-2003" in ids, "an order at 23:59:59 on the boundary day must be included"
    assert "ORD-2006" not in ids, "the day before the boundary must stay excluded"


# spec: SPEC-ORD-004/R3, SPEC-API-001/R2
def test_invalid_created_after_returns_400(api_base: str) -> None:
    status, body = get_json(f"{api_base}/orders?created_after=2026-13-01")
    assert status == 400
    assert body["error"]["code"] == "invalid_created_after"


# spec: SPEC-ORD-004/R4
def test_created_after_combines_with_status_and_paging(api_base: str) -> None:
    status, body = get_json(
        f"{api_base}/orders?status=paid&created_after=2026-09-14&page=2&page_size=1"
    )
    assert status == 200
    assert body["total"] == 2
    assert body["pages"] == 2
    assert [item["id"] for item in body["items"]] == ["ORD-2006"]
```
