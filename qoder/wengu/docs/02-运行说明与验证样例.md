# 运行说明与验证样例

> 目标：评审拿到仓库后，按本文档能从零跑到四个接口全部可用。
> 所有数字都来自本机实测（Windows 11 + Python 3.13 + seekdb v1.4.0 容器）。

## 一、环境

| 项 | 版本 / 要求 |
|---|---|
| Python | 3.11+（实测 3.13） |
| seekdb | `oceanbase/seekdb:latest`（实测 v1.4.0，容器 819 MB） |

## 三、验证样例

### V1 · 混合检索命中（核心）

- **输入**：提问框输入「非阻塞通信会造成死锁吗」
- **操作**：点「检索」
- **预期**：3 条引用卡片，第 1 条出处是《MPI 点对点通信》>> 死锁的四种典型成因
- **技术作用**：一条 SQL 内完成向量（`l2_distance ... APPROXIMATE`）+ 全文（`MATCH ... AGAINST`）+ 标量过滤，RRF 融合
- **实测**：延迟约 100–500 ms，`qa_log` 有对应记录

### V2 · 拒绝编造（负向验证）

- **输入**：「红烧肉怎么做好吃」
- **预期**：回答「资料中未提及」，不返回任何引用
- **判据**：查询 bigram 覆盖率低于 0.25 时判 `no_evidence`
- **实测**：覆盖率 0.0，三条无关问题（红烧肉 / 量子退火 / 股市）全部正确拒绝

### V3 · 出题与判分（技术结合）

- **操作**：出题区填「伪共享」→ 点「出题」→ 等 5–10 秒
- **预期**：生成一道简答题，状态行显示出处与「模型生成」
- **操作**：写下答案 → 点「提交判分」
- **预期**：显示 ✅/❌ 与理由；答错时尝试写入记忆，PC 未接入会明确提示「记忆未写入」
- **实测**：`/api/quiz` 返回 `llm_used=true`；`/api/grade` 200 且判定与理由一致

### V4 · 事实核查（可核对的具体数字）

- **输入**：「Amdahl 定律的加速比上限」
- **预期**：Top1 出处是《并行性能与可扩展性》>> Amdahl 定律：串行部分的暴政
- **可核对**：该节表格里 `s=5%`、`p=8` 应为 **5.9**（`1/(0.05+0.95/8)=5.93`），这是语料修订后的值

## 四、技术分工

| 组件 | 存什么 / 查什么 | 不做什么 |
|---|---|---|
| **seekdb** | 9 张表：文档状态、切片正文与向量、概念词表、概念关系、题目、答题记录、查询日志。一条 SQL 完成混合检索 | 不存用户弱点与进度 |
| **PowerContext** | 每个学习者一个 scope 的 weakness / progress / preference | 不存文档正文与向量 |
| LLM | 出题、判分、讲解 | 不负责检索与记忆 |

一句话：**seekdb 记得「资料说了什么」，PowerContext 记得「你哪里不会」**。

## 五、已知限制（不掩饰）

1. **PowerContext 当前是占位实现**。`/api/profile` 返回 fixture 数据，`app/memory.py` 的客户端已按 4 个端点写好，接上真服务即可切换。判分后界面会明说「记忆未写入」，不会假装成功。
2. **检索验收 5/7**。「伪共享」与「MPI_Allreduce 通信量」两条排到了相邻小节——两节共享 `共享` / `Allreduce` 这类 bigram，词法与语义都难以区分。已知的三个改进方向写在 `docs/01-需求与方案.md` §6。
3. **出题偶发退回模板**。qwen 免费额度有每分钟限流，撞上 429 时降级为「请简述 XXX 的核心内容」，状态行标注「模板兜底」。

## 六、数据与许可

语料是 6 篇自编并行计算讲义（1.27 万字 / 23 节），CC BY 4.0，不含任何第三方材料与个人信息。详见 `data/CORPUS.md`。

## 七、出问题怎么查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Can't find FULLTEXT index` | 表是旧版建的，索引还挂在 `content_seg` | 按 §4.2 重建表，再 `python -m app.ingest` |
| 全文命中恒为 0 | 用了 `IN BOOLEAN MODE` | 中文 ngram 必须用自然语言模式，见 §4.10 |
| `Using vector index without const param` | ANN 查询传了列而不是常量向量 | 查询侧必须传 `%(qvec)s` |
| 出题很慢 / 退回模板 | 百炼限流 429 | 等一分钟重试 |
| 判分总显示「记忆未写入」 | PowerContext 未接入 | 预期行为，见限制 1 |
