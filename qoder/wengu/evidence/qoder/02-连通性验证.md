## 踩坑记录

**问题**：PowerContext 端点路径是推测的，实际 API 与文档不同

**Qoder 处理**：
1. 先按文档推测路径测试，得到 404
2. 把报错原文贴回 Qoder
3. Qoder 分析后建议查看实际 API 文档
4. 实测发现真实端点是 `/v1/memory/remember` 等
5. 修改 `app/memory.py` 的 4 个常量，其他代码不动

**教训**：端点未知风险收敛到 4 行常量，改一处不影响全局
