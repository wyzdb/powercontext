## Qoder 对话要点

### 提示词核心内容

```
【目标】
1. 选题策略：从 weakness 里按 (count × 时间衰减) 排序，优先出「学过但反复错」的概念
2. 出题必须检索该 concept 的资料片段作为依据
3. 判分：选择题直接比对；简答题用 LLM 打分并给理由
4. 判分后写回：错 → upsert_weakness(count+1, status 回退到"新学")；对 → advance_progress 前进一档
5. GET /api/today/{learner} → 今日复习清单
6. 前端加"今日复习"入口

【约束】
- 出题不许脱离资料自由发挥，每题必须能点开到依据段落
- 状态机只有三档，不要自己加档位
```

### Qoder 完成的工作

1. **状态机**：新学 → 巩固 → 掌握，三档不可跳
2. **写回逻辑**：答错 count+1 并回退到「新学」，答对 streak+1 并升档
3. **复习清单**：按 count 降序排列，已掌握的概念移出

### 状态机设计

```
新学 --连对 1 次--> 巩固 --再连对 2 次 (累计 3)--> 掌握
 ^                                              |
 └----------- 错 1 次回退到「新学」，count+1 <---┘
```

### 实测结果

**错误累积**
```
对 learner=demo 连续答错「伪共享」3 次：
  第 1 次：count=1, status=新学
  第 2 次：count=2, status=新学
  第 3 次：count=3, status=新学
→ profile 里该概念 count=3、status 回到「新学」✓
```

**掌握后移出清单**
```
连续答对同一概念 3 次：
  第 1 次：streak=1, status=巩固
  第 2 次：streak=2, status=巩固
  第 3 次：streak=3, status=掌握
→ 从今日清单里消失 ✓
```

## 技术结合亮点

**这一轮是「技术结合」的真正落点：**

- 出题选题 → 读 PowerContext 弱点
- 出题依据 → 读 seekdb 资料片段
- 判分结果 → 写回 PowerContext
- 复习清单 → 读 PowerContext + seekdb 概念关系

**一句话概括整条链：**
> 资料在 seekdb 里不动，人的状态在 PowerContext 里累积；每次交互都是「读记忆 → 查资料 → 写记忆」。
