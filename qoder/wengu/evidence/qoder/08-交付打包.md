1. **异常处理**：6 种异常情况的明确返回
2. **一键脚本**：`scripts/init_demo.sh` 从零到跑通
3. **文档完善**：README、运行说明、验证样例
4. **证据索引**：所有证据文件的交叉引用

### 关键产出

- `scripts/init_demo.sh`：一键启动脚本

- `requirements.txt`：Python 依赖清单
- `SUBMISSION_GUIDE.md`：竞赛提交指南
- `evidence/INDEX.md`：证据索引

### 异常矩阵

| 情况 | 返回 | 上层动作 |
|------|------|---------|
| 空 query | `{"code": "empty_query", "message": "问题不能为空"}` | 前端提示 |
| 超长 query | `{"code": "query_too_long", "message": "问题过长，最多 500 字"}` | 前端提示 |
| embedding 超时 | `{"code": "embed_unavailable", "message": "向量化或检索失败"}` | 503 |
| seekdb 断开 | `{"code": "db_unavailable", "message": "seekdb 不可用"}` | 503 |
| PC 401 | `{"source": "unavailable", "note": "..."}` | 降级提示 |
| 判分非法 JSON | `{"correct": false, "feedback": "错 判分失败：..."}` | 显示理由 |
