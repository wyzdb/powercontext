## 本轮目标

## Qoder 对话要点

### 提示词核心内容

```
【目标】
产出 app/main.py（FastAPI）+ web/index.html（单页，纯 HTML+fetch，无 npm、无构建）：
1. POST /api/ask {learner, query} → 混合检索 + 带引用的回答
2. GET /api/profile/{learner} → 弱点列表、各概念状态、推荐复习顺序
3. POST /api/quiz {learner, concept?} → 出 3 道题
4. POST /api/grade {learner, answers} → 判分 + 讲解，错题写回弱点
5. 前端三个区：提问 / 出题 / 我的弱点

【约束】
- 回答必须带出处，无出处的结论不许输出
- 统一错误结构 {code, message}，不要把 stack trace 返回给前端
- 冷启动一条命令：uvicorn app.main:app --port 8080
```

### Qoder 完成的工作

1. **FastAPI 应用**：4 个端点（ask, quiz, grade, profile）
2. **单页前端**：纯 HTML+JS，三个功能区
3. **LLM 集成**：用 Qwen-plus 出题和判分
4. **错误处理**：统一错误结构，不暴露 stack trace

### 关键产出

- `app/main.py`：260 行 FastAPI 应用
- `web/index.html`：300 行单页前端

### API 端点

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/ask` | POST | 带出处的混合检索 |
| `/api/quiz` | GET | 按概念出题 |

## 踩坑记录

**问题**：出题偶发退回模板

**原因**：qwen 免费额度有每分钟限流，撞上 429 时降级

**Qoder 处理**：
1. 限流时降级为「请简述 XXX 的核心内容」
2. 状态行标注「模板兜底」
3. 不伪造 `llm_used=true`

**设计决策**：
- 前端用 `textContent` 而非 `innerHTML`，防止 XSS
- 所有数据不进 HTML，只进 textContent
- 这是安全底线，不是可选项
