1我这轮的提示词
【目标】
  1. 选题策略：从 weakness 里按 (count × 时间衰减) 排序，优先出「学过但反复错」的概念
  2. 出题必须检索该 concept 的资料片段作为依据，题目要能溯源到 source_file + heading_path
  3. 判分：选择题直接比对；简答题用 LLM 打分并给理由
  4. 判分后写回：错 → upsert_weakness(count+1, status 回退到「新学」)；对 → advance_progress 前进一档
  5. 今日复习清单 + 前端「今日复习」入口

【约束】
- 出题不许脱离资料自由发挥，每题必须能点开到依据段落
- 状态机只有三档，不要自己加档位

【验收】连续答错同一概念 3 次 → count=3 且回到「新学」；连续答对 3 次 → 「掌握」并从今日清单消失

STATUS_ORDER = ["新学", "巩固", "掌握"]

def advance_progress(learner, concept) -> dict:
    prev = _latest_by_concept(get_entries(learner)).get(concept)
    streak = int(prev.get("streak", 0)) + 1 if prev else 1
    # docs §4.7.2：连对 1 次→巩固，累计 3 次→掌握，中间不跳档
    nxt = "掌握" if streak >= 3 else "巩固"
    aid = remember(learner, "progress", {"concept": concept, "count": …,
        "streak": streak, "status": nxt, "evidence": "答对一次", "at": int(time.time())})

def upsert_weakness(learner, concept, wrong_answer):
    count = int(prev.get("count", 0)) + 1 if prev else 1
    remember(learner, "weakness", {"concept": concept, "count": count,
        "status": "新学",            # ← 回退就写在这里，不做「扣半档」
        "evidence": wrong_answer[:300], "at": int(time.time())})

4本轮踩坑与遗留
  • 档位不能用「每次调用 +1 格」实现：最初 advance_progress 直接走一格，答对 2 次就「掌握」，与 §4.7.2 的累计 3 次不符。改成显式 streak 计数 + streak>=3 才到掌握。
  • 时间衰减是纯计算，不该新增端点：at 字段每条记忆都写了，排序读不读是本地纯计算 —— PC 那边没有 /review_plan 这种东西，也不能有。
  • 遗留（不掩饰）：① weakness 与 progress 目前共用 concept 键做读侧收敛，同 count 时后写的那条覆盖前一条 —— 所以「伪共享」有 巩固 的 progress 记录，profile 仍显示 新学；文档规定的「以 progress 为准并回显告警」还没实现，应按 kind 分桶。② get_review_plan() 未落地，前端今日区字段口径（review_plan / concept_name）与 /api/profile 返回的 concept 不一致。③ concept_edge 仍 0 行，前置依赖排序暂时用不上。
