# 温故 · 演示脚本与截图指南

> 用于竞赛提交和现场演示

## 一、60 秒演示脚本

### 分镜 1：开场（0-10 秒）

**画面**：项目网站首页  
**旁白**：「这是温故，一个会记住你弱点的复习教练。它用 seekdb 做混合检索，用 PowerContext 做跨会话记忆。」

**操作**：打开 https://wengu-study-coach-ao0rgkrp2dz.qoder.zone

---

### 分镜 2：提问检索（10-25 秒）

**画面**：Web UI 提问区  
**旁白**：「输入问题，系统从讲义中检索最相关的段落，每条结果都带精确出处。」

**操作**：
1. 在提问框输入「非阻塞通信会造成死锁吗」
2. 点击「检索」
3. 展开第 1 条引用卡片，显示出处《MPI 点对点通信》>> 死锁的四种典型成因

**技术点**：一条 SQL 完成向量 + 全文 + 标量过滤，RRF 融合排序

---

### 分镜 3：拒绝编造（25-35 秒）

**画面**：Web UI 提问区  
**旁白**：「资料里没有的内容，系统会明确说查不到，不编造答案。」

**操作**：
1. 在提问框输入「红烧肉怎么做好吃」
2. 点击「检索」
3. 显示「资料中未提及」

**技术点**：bigram 覆盖率低于 0.25 时判 `no_evidence`

---

### 分镜 4：出题判分（35-50 秒）

**画面**：Web UI 出题区  
**旁白**：「按概念出题，答完让模型判分。答错会记进弱点档案。」

**操作**：
1. 出题区填「伪共享」→ 点击「出题」
2. 等待 5-10 秒，显示生成的简答题
3. 写下答案 → 点击「提交判分」
4. 显示 ✅/❌ 与理由

**技术点**：LLM 出题判分，答错写回 PowerContext

---

### 分镜 5：跨会话记忆（50-60 秒）

**画面**：Web UI 弱点区  
**旁白**：「弱点档案存在 PowerContext 里，跨会话持久化。下次打开，系统知道你是谁、哪里不会。」

**操作**：
1. 显示「我的弱点」表格
2. 显示「今日复习」清单
3. 强调：关闭应用再打开，记忆仍在

**技术点**：PowerContext scope 持久化，不依赖应用进程

## 三、现场演示注意事项

### 环境准备
1. 确保 seekdb 容器运行：`docker ps | grep seekdb`
2. 确保 PowerContext 服务运行：`curl http://127.0.0.1:8000/health/ready`
3. 确保应用已启动：`python -m uvicorn app.main:app --port 8080`
4. 浏览器打开：http://127.0.0.1:8080

### 演示顺序
1. 先展示项目网站（https://wengu-study-coach-ao0rgkrp2dz.qoder.zone）
2. 再展示本地应用（http://127.0.0.1:8080）
3. 按 60 秒脚本顺序演示

### 常见问题预案
- **出题很慢**：qwen 限流，等一分钟重试，或接受「模板兜底」
- **PowerContext 未接入**：预期行为，profile 返回 `source: "unavailable"`
- **检索结果为空**：检查 seekdb 是否运行，语料是否导入
