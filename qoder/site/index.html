The problem

“上次看到的那篇笔记，
到底在哪？”

文献、实验记录和组会 TODO 分散在文件夹、聊天记录和脑内。检索靠关键词，换一个说法就找不到；跨会话后，助手不记得你在做什么方向、上次卡在哪。

01

研究资料检索

笔记标题、正文和标签统一写入 seekdb 表；查询返回命中片段和可核对的来源 seekdb://rf_notes/...。

02

研究记忆画像

兴趣、阶段、下一步目标写入 PowerContext Memory。重启模块后读取同一画像，不需要重新介绍自己。

03

记忆驱动推荐

把读取到的兴趣拼成查询，再从 seekdb 召回相关笔记。记忆不是摆设，直接改变推荐结果。

How it works

一次完整的研究闭环

  1. 导入笔记写入 seekdb rf_notes 表
  2. 检索按标题/正文/标签打分，返回真实来源
  3. 记住用户画像写入 PowerContext Memory
  4. 继续重启后读记忆，生成下一步推荐

Run it

三分钟体验

cd qoder
export PYTHONPATH="$(cd .. && pwd)/src"
pip install -r requirements.txt
python validation/run.py sqlite
uvicorn app.main:app --reload

打开 http://127.0.0.1:8000：检索 “transformer attention”，保存研究画像，再点击“读取记忆并推荐”。也可以运行 python validation/run.py seekdb 使用 Linux 上的 seekdb 绑定。
