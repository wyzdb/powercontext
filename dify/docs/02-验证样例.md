# 验证样例

> 运行环境与初始化步骤见 [01-斗地主-执行手册.md](01-斗地主-执行手册.md)。
> 所有样例都在 `http://localhost:8080`（Dify）上实测通过，截图见 `evidence/`。

---

## V1 · 开局（2 分钟）

**初始状态**：新开一个对话，玩家 ID 留空（或不填）。

| 步骤 | 输入 | 预期 |
|---|---|---|
| 1 | `开始` | 返回第 1 关牌桌：手牌 `3 3 5 6 7 8 9`（7 张）、左家剩 3 张、剩余步数 2；老K 接一句调侃 |

**实际运行结果**

```
【第 1 关 · 顺子开路】
你的手牌（7 张）：3 3 5 6 7 8 9
左家：剩 3 张
轮到你自由出牌
剩余步数：2

老K：哟，七张牌就敢来闯关？
老K：顺子倒是齐整，可惜——地主不收拾装货。
```

证据：`evidence/04-ui-open.png`

## V2 · 两步通关（1 分钟）

**初始状态**：接 V1，同一对话。

| 步骤 | 输入 | 预期 |
|---|---|---|
| 1 | `5 6 7 8 9` | 手牌剩 `3 3`，步数变 1；左家要不起 |
| 2 | `3 3` | `你赢了！你出完了`；提示「下一关」 |

**实际运行结果**

```
你的手牌（2 张）：3 3
左家：剩 3 张
剩余步数：1

（输入 3 3 后）
你赢了！你出完了
通关！说「下一关」继续。
```

同时 PowerContext 写入一条记录：

```
第 1 关 · 顺子开路：通关（2 步预算，用了 2 步）
```

证据：`evidence/05-ui-win.png`

校验命令：

```bash
cd ~/workspace/ddz/engine && python3 -c "
import json; d=json.load(open('puzzles.json',encoding='utf-8'))
print(d['puzzles'][0]['solution'])"
# [['5','6','7','8','9'], ['3','3']]
```

## V3 · 跨会话记忆（关键样例，1 分钟）

**初始状态**：V1/V2 已经打过一局，PowerContext 里已有该玩家的通关记录。

| 步骤 | 输入 | 预期 |
|---|---|---|
| 1 | 点「开启新对话」 | 新会话，会话变量重置 |
| 2 | 玩家 ID 填 `lxz`（与上一局相同） | — |
| 3 | 输入 `开始` | 老K **第一句就提上一关**，然后才说这一手牌 |

**实际运行结果**

```
老K：上回第1关你顺子开路，两步就飘了——这手7张牌，还剩3张的左家可没打哈欠呢。
```

证据：`evidence/06-ui-cross-session.png`

**为什么这能证明是"记忆"而不是模型瞎编**：
新会话里没有任何历史消息，`game_state` 也是空的；能说出"第 1 关、顺子开路、两步"，只能来自 PowerContext 召回。

## V4 · 对照组（可选，30 秒）

**目的**：排除"模型自己编造旧事"。

| 步骤 | 输入 | 预期 |
|---|---|---|
| 1 | 新对话，玩家 ID 填一个**没用过**的名字（如 `ceshi-001`） | — |
| 2 | 输入 `开始` | 老K **不提**任何"上次/上回/之前"，只评论当前手牌 |

判断标准：V3 提旧事、V4 不提，两者对照成立，记忆链路才算被证明。

---

## 恢复初始状态

| 想重置什么 | 怎么做 |
|---|---|
| 牌局进度 | 点「开启新对话」（会话变量清空，回到第 1 关） |
| 玩家记忆 | 换一个玩家 ID（不同 ID = 不同 scope） |
| 知识库 | 不用动，只读 |

> 需要彻底清空某个玩家的记忆时，可在 PowerContext 里按 scope 删除；演示时换 ID 更快。
